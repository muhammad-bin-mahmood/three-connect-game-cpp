# 🕹️ Connect Three (C++ Console Game)

A simple two-player **Connect Three** game built in **C++** using loops and basic logic.  
Similar to Tic Tac Toe, but instead of placing symbols directly, players **drop** their pieces (`A` or `B`) into one of three columns — each piece automatically falls to the lowest available position in that column (like a mini Connect Four).

---

## 🧩 How to Play
1. Run the program.  
2. Player **A** starts first.  
3. Enter a **column number (1–3)** to drop your piece.  
4. The piece automatically fills the lowest available cell in that column.  
5. Keep playing until:
   - A player gets **three in a row, column or diagonal**, or  
   - The board is completely filled (game ends in a draw).
